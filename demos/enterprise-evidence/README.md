# Enterprise replay evidence

These reports were generated by ForgeAI from the bundled synthetic sources. People Operations is a same-corpus holdout. The observatory pack is a separate brief and corpus from the four original demos. Its development and holdout cases are both generated from the observatory sources.

| Replay | Development | Blind holdout | Fixed conformance |
| --- | ---: | ---: | ---: |
| People Operations | 24/24 | 8/8 | 4/4 checks run, 1 inapplicable |
| Observatory Volunteers | 24/24 | 8/8 | 4/4 checks run, 1 inapplicable |

Run the observatory example from the repository root.

```bash
python -m forgeai build \
  --no-model --unseen-corpus --security-audit \
  --brief-file demos/enterprise-evidence/observatory/brief.txt \
  --docs demos/enterprise-evidence/observatory/documents \
  --out .runs/observatory
```

Then query the generated agent with the same source folder.

```bash
python -m forgeai chat --no-model \
  --definition .runs/observatory/definition.json \
  --docs demos/enterprise-evidence/observatory/documents \
  --ask "Look up AST-200"
```

The [People Operations language report](people-ops/language-evaluation.json) used local Qwen 2.5 0.5B as the translator. English passed both cases, Hindi remained unverified, and Tamil was unavailable. The [model comparison](people-ops/model-tournament.json) reached the same grounded results through the deterministic path and returned no model recommendation.
