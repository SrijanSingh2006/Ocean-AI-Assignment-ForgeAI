# Dockside delivery

The buyer must provide the terminal gate, berth number, and consignee phone number for dockside delivery. The carrier needs the details by 14:00 on the prior working day.

# Port storage

The port holds packages for up to 48 hours after unloading. Holding charges apply after the storage window ends.

# Collection windows

Standard collections take place Monday to Friday between 07:00 and 16:00. The driver must show the delivery reference and photo ID.

# Pallet labeling

Tag pallets with the vessel name, order number, and berth identifier. Put a duplicate label inside each weatherproof document pouch.

# Weekend handling

Weekend dock handling requires written authorization from the terminal supervisor. Submit requests before noon on the preceding Thursday.
